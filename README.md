# Make-a-Wish Proxy

A Node.js Express proxy server that connects to the Roblox Creator Store API.

## Features

- 🔎 Search Roblox Creator Store assets
- 🔐 Keeps Roblox API keys secure using environment variables
- ⚡ Express.js API proxy
- 🌐 Ready for deployment on Render

## Tech Stack

- Node.js
- Express.js
- Axios
- dotenv
